# Q-PRISM

Қазақ тіліндегі Q-PRISM веб-қосымшасы — Қызылорда қаласындағы әлеуметтік маңызы бар азық-түлік (СЗПТ) бағаларын бақылау үдерісін көрсетуге арналған демо. Ұраны: «Баға сигналы → негізделген әрекет».

## Қолдану

```bash
npm install
npm run dev
```

Vite көрсеткен жергілікті мекенжайды браузерде ашыңыз. Өндірістік жинақ: `npm run build`; жинақты жергілікті қарау: `npm run preview`.

## Мүмкіндіктер

- Шолу: дерек қамтуы, басым әрекеттер және синтетикалық сигнал.
- Карта және тапсырмалар: шартты аумақ схемасы, демо нүктелері, тапсырма тағайындау, мәртебені және аналитикалық қорытындыны бөлек көрсету.
- Сигналдар: медианалық баға динамикасының түсіндірмесі, бірлік/мерзім/таңдама, шағын таңдама туралы ескерту.
- СЗПТ анықтамалығы: ресми жарияланған 31 тауар позициясы және бір стильдегі жергілікті SVG суреттері.
- Есептер: демо бақылаулардан құрылады UTF-8 BOM CSV; PDF браузердің басып шығару терезесі арқылы сақталады.
- Дерек енгізу/сапасы: кг/л/10 данаға нормалау, форма тексеруі, CSV алдын ала қарауы, қате/дубль кезегі.
- ҚАЗ/РУС батырмасы — негізгі навигация, тауар/аудан атауы және негізгі интерфейс белгілерінің тілін ауыстырады. Терең аналитикалық түсіндірмелердің кейбірі қазақша ғана.
- Рөл таңдау — тек демонстрациялық алдын ала көру. Аутентификация жоқ.

## Демо деректері мен шектеулері

Баға бақылаулары, сигналдар, «Демо нүкте A/B/C», аудан қамтуы, қызметкерлер мен тапсырмалар толығымен синтетикалық. Бұлар нақты Қызылорда бағасы, дүкендер тізілімі не нақты мониторинг нәтижесі емес. Нүктелерде расталған мекенжай/координат жоқ; карта схемалық. Нақты филиалдың координаты немесе жауапты инспекторы тексерілген жоқ.

Бақылау қосу тек ашық браузер қойындысының React күйінде тұрады: серверге жіберілмейді және бетті жаңартқанда жойылады. Фото сақтау, толық CSV импорт/валидация, геокодтау/Leaflet картасы, сервер API және тіркелгі жүйесі іске қосылмаған. CSV импорт тек алдын ала қарау жасайды; жүктелген жолдар дерекке қосылмайды. PDF экспорт — браузердегі басып шығаруға арналған көрініс.

Сигналдар себепті болжай алмайды және заң бұзушылықты анықтамайды. Медиана шеткі мән әсерін азайтатын қарапайым агрегат; шағын таңдамада қорытынды тұрақсыз. Үштен аз бақылауда аудандық кесінді жеткіліксіз деп көрсетіледі. Демо цифрлар тек сценарийге арналған.

## Тексеру күйі

npm run build өндірістік құрастыруын орындап тексердім. Браузерге жергілікті серверді ашу мүмкін болмады: Codex браузері localhost-қа қосыла алмады, ал sandbox ортада dev серверді фондық іске қосу бұғатталды. Сондықтан шолу/тағайындау/мобильді енгізу/PDF жүктеу сценарийлері UI-де қолмен расталған жоқ.

## Дереккөздер

31 атау тапсырмадағы базалық тізімді 2026 жылы gov.kz сайтында жарияланған тізіммен салыстыру арқылы енгізілді (`DATA_SOURCES.md`). Екі HTML прототип интерфейс идеясы ретінде қаралды. Қосымша мәтіндік жазбалардағы жергілікті сауда нүктелері мен процесс туралы расталмаған тұжырымдар факт ретінде пайдаланылмады. Тіркелген мәтіндерден дүкен/координата тізілімінің расталған дерегі табылмады. PDF файлдары табылды, бірақ мәтінін осы ортада шығарып оқу құралы болмады; толық мәтінді тексеру мүмкін болмады. Талаптар осы чатта берілген тапсырма мәтіні бойынша орындалды. Бұл жұмысты тоқтатқан жоқ.

Есеп мазмұны, әдіс пен шағын таңдама suppression қағидасы `REPORT_METHODOLOGY.md` ішінде. Бұл — аналитикалық демо, ресми мемлекеттік статистика емес. Бақыланған баға мен статистикалық сигнал өздігінен заң бұзушылықты білдірмейді.

GitHub Pages ашық статикалық сайт. Оған құпия, жеке, ішкі немесе сауда құпиясы деректерін, API кілттерін қоспаңыз. Бұл прототип ОФД, ЭСФ, Smart Bridge, e-Otinish, Telegram, НКТ немесе басқа мемлекеттік жүйеге қосылмаған.
