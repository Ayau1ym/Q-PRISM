# Q-PRISM

Демо-система для работы с наблюдениями цен на социально значимые продовольственные товары в Кызылорде. Интерфейс доступен на русском и казахском языках; основной шрифт — Inter.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка и локальный просмотр:

```bash
npm run build
npm run preview
```

Подробная публикация в GitHub Pages описана в [DEPLOY_GITHUB.md](DEPLOY_GITHUB.md).

## Что можно показать

- Четыре разных режима: координатор, аналитик, инспектор и житель. Переключатель роли меняет и навигацию, и стартовый рабочий экран. Это предпросмотр ролей, без паролей и настоящей авторизации.
- Карта Кызылорды с панорамированием и масштабом на Leaflet/OpenStreetMap. Маркеры — условные демо-точки; торговые точки и координаты не подтверждены.
- Координатор смотрит обзор и карту, фильтрует и назначает задачи, меняет статусы.
- Аналитик сравнивает медиану по товару, району и периоду; таблица импорта показывает ошибки и дубликаты, позволяет поправить значения прямо в строке, удалить проблемные строки и добавить корректные записи в демо-набор.
- Инспектор заполняет полевой результат, загружает фото ценника и сохраняет снимок вместе с демо-наблюдением.
- В фото-разделе есть локальный SVG-ценник и кнопка тестового сценария распознавания. Это имитация потока для показа, не OCR и не компьютерное зрение: тестовые значения требуют ручного подтверждения.
- Импорт поддерживает CSV, TSV и XLSX. Кнопка скачивания примера создаёт таблицу с корректной строкой, дубликатом и ошибочной ценой.
- Раздел жителя доступен без входа. PDF скачивается напрямую с кириллическим шрифтом, CSV — в UTF-8 с BOM. Для малых выборок (меньше трёх наблюдений) цена скрывается.
- Каталог включает 31 демонстрационную позицию с локальными SVG-иллюстрациями.

## Демо-данные и ограничения

Все цены, наблюдения, задачи, сотрудники, охват и названия демо-точек синтетические. Данные живут только в состоянии текущей вкладки: они не отправляются на сервер и сбрасываются после перезагрузки. Сайт не подключён к государственным системам и не определяет причину изменения цен или факт нарушения.

Карта использует тайлы OpenStreetMap и требует интернет-соединения. Маркеры расположены приблизительно для демонстрации карты и не обозначают подтверждённые магазины. Источник карты указан в атрибуции Leaflet.

Импорт XLSX выполняется локально в браузере. Макросы не запускаются; файл и значения не загружаются на сервер. Перед импортом проверьте предварительный просмотр и исправьте неподходящие товарные названия в строках.

## Проверка в этой сборке

`npm run build` выполнен успешно. Встроенный браузер Codex не смог соединиться с локальным сервером, поэтому ручная браузерная проверка интерактивных сценариев, внешних картографических тайлов и реального скачивания PDF здесь не подтверждена.

Торговые точки и источники данных описаны в [DATA_SOURCES.md](DATA_SOURCES.md), а правила отчёта — в [REPORT_METHODOLOGY.md](REPORT_METHODOLOGY.md). Не добавляйте закрытые данные, персональные сведения и ключи в публичную сборку.
